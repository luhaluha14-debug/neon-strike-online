# NEON STRIKE Online

브라우저로 하는 온라인 멀티플레이 FPS입니다. 방 하나에 최대 6명(DUEL은 2명)이 들어가며, 사람끼리만 대전합니다.

- **빠른 매칭**: 공개 방에 자동으로 들어갑니다. 2명이 모이면 8초 뒤 자동으로 시작합니다.
- **방 만들기 / 코드 입장**: 4자리 코드를 친구에게 알려주면 됩니다. 방장이 모드와 맵을 고르고 시작합니다.
- 경기 중에 들어온 사람은 바로 경기에 합류합니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `public/index.html` | 게임 본체 (오프라인 봇 대전도 그대로 가능) |
| `public/net.js` | 온라인 접속, 로비/방 화면, 다른 플레이어 표시 |
| `server/server.js` | 웹 서버 + WebSocket (`/ws`) + 방 목록 |
| `server/game.js` | 방 한 개의 경기 규칙 (체력, 피해, 킬, 점수, 부활, 궁극기) |
| `server/shared.js` | `index.html`에서 영웅, 맵, 충돌 코드를 그대로 읽어옴. 서버와 게임이 항상 같은 맵으로 판정합니다 |
| `test/server-test.js` | 서버 자동 테스트 (`npm test`) |
| `test/dummy.js` | 혼자 테스트할 때 쓰는 가짜 상대 |

## 1. 내 컴퓨터에서 실행

[Node.js](https://nodejs.org) 18 이상이 필요합니다.

```bash
npm install
npm start
```

- 브라우저에서 `http://localhost:8080`을 열고 **ONLINE**을 누르세요.
- 같은 와이파이의 친구는 서버 창에 표시되는 `http://192.168.x.x:8080` 주소로 접속합니다.
- Windows 방화벽 허용 창이 뜨면 "개인 네트워크"를 허용해야 친구가 들어올 수 있습니다.

### 혼자 테스트하기

```bash
node test/dummy.js ABCD BOT sniper --shoot
```

`ABCD` 자리에 방 코드를 넣으면 가짜 상대가 들어와서 좌우로 움직이며 총을 쏩니다. `quick`을 넣으면 빠른 매칭으로 들어갑니다.

## 2. 인터넷에 공개하기 (Render 무료 플랜 예시)

1. 이 폴더를 GitHub 저장소로 올립니다. `node_modules`는 `.gitignore`로 제외됩니다.
2. [render.com](https://render.com)에 가입하고 **New → Blueprint**를 누른 뒤, 저장소를 선택합니다.
   - 저장소에 들어 있는 `render.yaml`이 설정을 자동으로 채웁니다.
   - 직접 설정하려면 **New → Web Service**를 고르고 Build `npm install`, Start `npm start`를 입력합니다.
3. 배포가 끝나면 나오는 `https://….onrender.com` 주소를 공유하면 됩니다. 접속은 자동으로 `wss://`로 됩니다.

무료 플랜 참고 사항:
- 한동안 아무도 접속하지 않으면 서버가 잠듭니다. 첫 접속이 30초~1분 정도 느릴 수 있습니다.
- 서버가 재시작되면 진행 중인 방이 사라집니다.

Fly.io, Railway 같은 다른 Node 호스팅도 같은 방식(`npm install` → `npm start`, `PORT` 환경변수 사용)으로 동작합니다.

## 판정 방식과 한계

- 각 플레이어는 자기 캐릭터의 이동을 직접 계산하고, 명중했다고 서버에 알립니다. 반응이 즉각적인 대신 이런 구조를 택했습니다.
- 서버는 모든 명중 주장을 검사합니다. 대상과의 거리, 조준선과의 거리, 벽 가림(최근 0.4초 위치 기준), 연사 속도, 무기 사거리, 스킬 쿨다운, 궁극기 게이지를 봅니다. 통과한 주장만 피해로 인정합니다.
- 체력, 피해량 계산, 킬, 점수, 부활 위치, 궁극기 게이지는 모두 서버가 정합니다.
- **한계:** 이 구조로는 에임봇(자동 조준)을 막을 수 없습니다. 이동 역시 순간이동 수준의 비정상 이동만 되돌립니다. 모르는 사람과 경쟁적으로 하는 게임으로 키우려면, 이동까지 서버가 계산하는 구조와 신고/차단 기능이 추가로 필요합니다.
- 다른 플레이어는 약 0.1초 전 위치로 부드럽게 보간해서 보여줍니다. 핑이 매우 높으면 상대가 조금 늦게 보일 수 있습니다.
