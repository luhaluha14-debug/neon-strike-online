# 주술 전선 (JUJUTSU FRONT)

브라우저에서 바로 실행되는 **수집형 턴제 RPG 프로토타입**입니다.
주술회전 스타일에서 영감을 받은 **비공식 팬메이드** 프로젝트이며,
원작의 이미지·음원·코드를 일절 사용하지 않고 **모든 그래픽을 런타임에 SVG로 생성**합니다.

## 실행 방법

```
jujutsu-rpg/index.html 파일을 브라우저로 열기만 하면 됩니다.
```

- 설치·빌드·서버 불필요 (단일 HTML 파일, 외부 리소스 0개)
- 지원: 모바일 세로/가로, 태블릿 세로/가로, 데스크톱

## 게임 루프

캐릭터 수집 → 부대 편성 → 턴제 전투 → 성장 → 스테이지 진행 → 보스 → 재화 → 소환 → 새 캐릭터

## 전투 시스템

| 요소 | 설명 |
|---|---|
| 행동 순서 | 속도 기반 Action Value 방식. 다음 6명의 순서를 화면에 표시 |
| 주력(SP) | 파티가 공유하는 자원(최대 6). 공격/방어로 +1, 스킬로 소모 |
| 필살기 | 캐릭터별 게이지 100%에서 발동. 컷인 연출, 일부는 **영역전개** |
| 브레이크 | 적의 BREAK 게이지를 0으로 만들면 행동 불가 + 받는 피해 35% 증가 |
| 버프/디버프 | ATK·DEF·SPD·치명타·받는 피해·지속 피해·기절·보호막·재생·도발 등 |
| 속성 상성 | 술식 → 주령 → 육체 → 저주 → 반전 → 술식 (유리 1.3배 / 불리 0.85배) |
| 적 AI | 상황 판단형. 보스는 고정 패턴을 사용하고 **다음 행동을 예고** |

전투 상태 머신: `PLAYER_TURN` · `SKILL_SELECT` · `TARGET_SELECT` · `ANIMATION` · `ENEMY_TURN` · `VICTORY` · `DEFEAT`

## 콘텐츠

- 캐릭터 **24종** (동일 인물의 다른 버전은 별도 캐릭터로 취급)
- 스테이지 **15개** (1-1 ~ 1-10, 2-1 ~ 2-5 / 보스 6종)
- 스토리 6화, 튜토리얼, 도감·부대·소환·상점·설정

## 코드 구조 (단일 파일 내 논리 분리)

```
Util / Art          유틸리티 · 절차적 SVG 생성기 (초상/주령)
DB                  캐릭터 · 스킬 · 적 · 스테이지 · 스토리 데이터
SaveSystem          localStorage 저장/로드/검증/마이그레이션 (saveVersion)
GameState           보유 캐릭터 · 재화 · 파티 · 진행도
CharacterSystem     스탯 계산 · 레벨 · 돌파 · 스킬 강화
AudioSystem         WebAudio 합성 효과음/BGM (파일 없음)
FX (AnimationSystem) 데미지 숫자 · 파티클 · 화면 흔들림 · 컷인 · 영역전개
BattleSystem        상태 머신 · 턴 · 데미지 · 스킬 · 브레이크 · 적 AI
BattleUI            전투 화면 렌더링
GachaSystem         확률 · 천장 · 중복 전환
StageSystem         스테이지 진행 · 보상
Tutorial            첫 전투 가이드
UI                  화면 전환 · 각 화면 렌더링
```

**캐릭터 추가는 데이터만 넣으면 됩니다.** `DB.CHARS` 배열에 항목을 추가하면
전투·도감·소환·성장에 자동으로 반영됩니다. (전투 코드 수정 불필요)

## 캐릭터 데이터 예시

```js
{
  id: 'gojo_aw', name: '고죠 사토루', version: '각성', rarity: 5,
  role: 'dps', el: 'tec',
  art: { hair: 'spiky', hairColor: '#f2f4ff', eye: '#59e7ff', marks: 'blindfold', ... },
  base: { hp: 1280, atk: 138, def: 78, spd: 108, crit: 12, cdmg: 62 },
  passive: { ... },
  skills: [ 무하한, 창, 혁, 허식「자」 ],
  ult: { name: '무량공처', domain: true, ... }
}
```

## 저장 데이터

`localStorage` 키 `jjkfront.save.v1` 에 저장됩니다.
보유 캐릭터·레벨·스킬 레벨·돌파·파티·재화·스테이지 진행·천장 카운터·설정이 유지되며,
손상된 데이터나 존재하지 않는 캐릭터 ID는 자동으로 기본값 복구됩니다.
설정 화면에서 **데이터 초기화**(2단계 확인)를 할 수 있습니다.

## 모바일 대응

- `env(safe-area-inset-*)` 기반 노치/홈 인디케이터 회피
- 최소 44px 이상의 터치 영역, Pointer Events 통합 입력, 연타/중복 입력 차단
- 세로/가로/태블릿/데스크톱 레이아웃 분리 (`#app[data-layout]`)
- 그래픽 품질(높음/중간/낮음), 전투 속도(x1~x3), 효과 감소, 글자 크기, 고대비 옵션

## 라이선스 / 고지

개인 학습용 팬메이드 프로토타입입니다. 상업적 이용을 하지 않으며
원작사와 무관합니다. 캐릭터 이름은 팬 창작의 범위에서 참조되었고,
모든 그래픽·연출·코드는 이 저장소에서 독자적으로 구현되었습니다.
