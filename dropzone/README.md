# NEON STRIKE: DROPZONE

PC와 모바일 브라우저에서 같은 코드로 돌아가는 3D 배틀로얄입니다. 지금은 **PHASE 1: 핵심 프로토타입** 단계입니다.
모든 무기, 맵, 캐릭터, UI, 사운드는 이 프로젝트를 위해 새로 만든 오리지널입니다. 사운드는 Web Audio로 실시간 합성하며 외부 에셋 파일을 쓰지 않습니다.

## 실행

```bash
cd dropzone
npm install
npm start                        # http://localhost:8090  (개발 빌드: F3 디버그)
NODE_ENV=production npm start    # 릴리스 빌드 (디버그 기능 비활성화)
npm test                         # 시뮬레이션 회귀 테스트 (17개)
```

같은 와이파이의 휴대폰에서는 서버 콘솔에 표시되는 `http://192.168.x.x:8090` 주소로 접속합니다.
PC 브라우저에서 `?touch=1`을 붙이면 모바일 조작 UI를 강제로 켤 수 있습니다.

## 기술 스택과 선택 이유

| 영역 | 선택 | 이유 |
|---|---|---|
| 렌더링 | three.js (WebGL) | PC·iOS·Android 브라우저에서 설치 없이 실행됩니다. 기존 NEON STRIKE와 같은 스택이고, 나중에 Capacitor로 앱 패키징도 가능합니다 |
| 게임 로직 | 순수 JS 모듈 (`shared/`) | DOM이나 three.js에 의존하지 않습니다. **같은 코드가 브라우저(오프라인)와 Node 서버(온라인 권한 서버)에서 그대로 돌아갑니다** |
| 서버 | Node + ws | 기존 서버와 같은 스택입니다. PC와 모바일이 같은 서버에 붙습니다 |
| 테스트 | `node --test` + Playwright | 시뮬레이션은 Node 단위 테스트로, 실제 화면은 헤드리스 Chromium으로 확인합니다 |

### 서버와 클라이언트의 역할 분리 (온라인 대비)

- 클라이언트는 **입력 명령**(이동축, 시점 각도, 버튼)만 만듭니다. 사람과 봇이 같은 명령 형식을 씁니다.
- `Match`(shared/game.js)가 이동, 탄약, 피해, 줍기, 사망, 자기장, 승리를 **모두** 판정합니다. 지금은 브라우저가 이 코드를 직접 돌리고, 온라인에서는 서버가 같은 코드를 권한을 가진 쪽으로 실행합니다.
- 산탄 퍼짐 같은 무작위 요소는 `(플레이어, 발사 번호, 매치 시드)`로 시드를 만들기 때문에, 클라이언트 예측과 서버 결과가 일치합니다.
- 이동 코드(`stepBody`)는 순수 함수입니다. 클라이언트 예측과 서버 재조정(reconciliation)에 그대로 쓸 수 있습니다.

## 조작 (PC 기본값, 설정에서 모두 변경 가능)

| 키 | 동작 | 키 | 동작 |
|---|---|---|---|
| WASD | 이동 | Shift | 달리기 |
| Ctrl | 걷기 | Space | 점프 |
| C | 앉기 | Z | 엎드리기 |
| 마우스 왼쪽 | 발사 | 마우스 오른쪽 | 조준 |
| R | 재장전 | F | 줍기 |
| 1~4 / 휠 | 무기 슬롯 | H | 빠른 회복 |
| Tab | 인벤토리 | M | 지도 |
| V | 1인칭/3인칭 | Alt | 자유 시점 |

모바일 조작: 왼쪽 화면은 떠다니는 가상 스틱이고, 가장자리 위로 밀면 달리기입니다. 오른쪽 화면은 드래그해서 시점을 돌립니다. 버튼은 발사(좌·우 2개), 조준, 점프, 앉기, 엎드리기, 재장전, 줍기, 무기 교체, 회복, 가방, 지도, 시점, 일시정지입니다.
설정의 **버튼 배치 변경**에서 버튼을 끌어 옮기고 크기를 바꿀 수 있습니다.
모바일 설정: 터치 감도, UI 크기, 버튼 크기, 버튼 투명도, 자동 사격, 조준 보조, 자이로, 진동, 자동 줍기.
